## 📚 30 Different HTML Tags

| # | 🏷️ Tag | 📖 Purpose |
|:---:|:---:|---|
| **01** | `<html>` | Root element of an HTML document |
| **02** | `<head>` | Contains document information and metadata |
| **03** | `<title>` | Defines the webpage title |
| **04** | `<body>` | Contains the visible webpage content |
| **05** | `<h1>` | Defines the main heading |
| **06** | `<p>` | Defines a paragraph |
| **07** | `<br>` | Creates a line break |
| **08** | `<hr>` | Creates a thematic break |
| **09** | `<a>` | Creates a hyperlink |
| **10** | `<img>` | Displays an image |
| **11** | `<strong>` | Indicates strong importance |
| **12** | `<em>` | Represents emphasized text |
| **13** | `<b>` | Draws attention to text with bold styling |
| **14** | `<i>` | Represents text in an alternate voice or mood |
| **15** | `<u>` | Represents underlined or annotated text |
| **16** | `<mark>` | Highlights text |
| **17** | `<small>` | Represents smaller or secondary text |
| **18** | `<sub>` | Displays subscript text |
| **19** | `<sup>` | Displays superscript text |
| **20** | `<pre>` | Displays preformatted text |
| **21** | `<div>` | Creates a block-level container |
| **22** | `<span>` | Creates an inline container |
| **23** | `<ul>` | Creates an unordered list |
| **24** | `<ol>` | Creates an ordered list |
| **25** | `<li>` | Defines a list item |
| **26** | `<table>` | Creates a table |
| **27** | `<tr>` | Defines a table row |
| **28** | `<td>` | Defines a table data cell |
| **29** | `<form>` | Creates a form for user input |
| **30** | `<input>` | Creates an input field |

## 🗂️ Tag Categories

| 📂 Category | 🏷️ Tags |
|---|---|
| 🏗️ **Document Structure** | `<html>`, `<head>`, `<title>`, `<body>` |

| 🔤 **Text Formatting** | `<sub>`, `<sup>`, `<pre>` |
| 🔗 **Links & Media** | `<a>`, `<img>` |
| 📦 **Layout & Containers** | `<div>`, `<span>`, `<br>`, `<hr>` |
| 📋 **Lists** | `<ul>`, `<ol>`, `<li>` |
| 📊 **Tables** | `<table>`, `<tr>`, `<td>` |
| 📝 **Forms** | `<form>`, `<input>` |
